## What is BePoly?

BePoly is a **grammar-first language learning web app** that gives you a personalized, structured lesson from any language book — no account needed, no setup, just learning.

Upload a PDF of your textbook or reading material, tell BePoly what you want to work on, and it generates a focused lesson tailored to your level — complete with a quiz and a read-aloud exercise.

---

## ✨ Features

- **📚 Bring Your Own Book** — Upload any language learning PDF and BePoly builds lessons from it
- **🤖 AI-Tailored Lessons** — Personalized content covering grammar, vocabulary, expressions, or reading comprehension
- **📝 Interactive Quizzes** — Test what you've learned right after each lesson
- **🔊 Read-Aloud Practice** — Improve pronunciation with guided paragraph reading
- **📊 Level Assessment** — BePoly gauges your proficiency and recommends what to study next
- **💡 Book Recommendations** — Get suggestions based on your language and level
- **🔒 No Login, No Sign-up** — Start learning immediately; progress is tracked locally in your browser

## 🚀 Getting Started

Visit **[bepoly.lovable.app](https://bepoly.lovable.app)** and hit **Start Learning** — no account required.

Or run it locally:

```bash
# Clone the repo
git clone https://github.com/your-username/bepoly.git
cd bepoly

# Install dependencies
npm install

# Start the dev server
npm run dev
```

## 🗺️ How It Works

```
1. Upload a PDF (or skip to use BePoly's book recommendations)
        ↓
2. BePoly assesses your level
        ↓
3. Pick a focus: Grammar / Vocabulary / Expressions / Reading
        ↓
4. Get a personalized lesson
        ↓
5. Take a quiz → Read aloud → Track your progress locally
```
